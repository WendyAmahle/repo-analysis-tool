Required features from the brief

  • Accept repositories by ZIP upload with .git and by remote URL clone.
  • Support multiple repositories in one dashboard.
  • Merge author identities using .mailmap; allow manual merging if missing.
  • Calculate file, directory, repository, commit-set, and author metrics.
  • Filter by repository, author, file/directory path, time period, or selected commits.
  • Ignore binary files and use rename detection at 50%.

This first baseline implements remote URL clone, multiple saved repositories, .mailmap author normalization, file/directory/repository/commit-set/author metrics, and the main filters. ZIP upload and manual author merging are intentionally left for the next iteration.
